# Laptop-electronic — Vorentis Next-Gen Commerce Platform

VORENTIS is an Awwwards-level next-generation technology showroom, cinematic editorial storefront, and high-performance computing platform engineered with Angular 19, GSAP ScrollTrigger, Lenis smooth scrolling, and 4K photorealistic 40-frame sequence animations.

## Key Features

- **Hero 40-Frame Video Scroller**: Pinned GSAP ScrollTrigger sequence scrubbing through 40 high-resolution 2560x1440 dark studio frames.
- **Architectural Manifesto**: Masked typography reveals and real-time counting telemetry dials.
- **360° Hardware Turntable**: Interactive 4K frame turntable with physics drag rotation, auto-spin mode, and finish swatches.
- **CAD-Style Hardware Blueprint**: Layered hardware teardown and thermal component inspection.
- **2026 Silicon Lineup Discovery Grid**: Product Card 2.0 with cursor displacement parallax, spec peek drawer, and quick add.
- **"Find My Device" AI Configurator**: Multi-step interactive consultation with matching score algorithm.
- **Synchronized 3-Product Comparison Matrix**: Side-by-side spec comparison highlighting best performance, value, battery, and display.
- **Command-K Universal Search**: Modal search palette with instant keyboard navigation.
- **Cart Drawer & Frictionless Checkout**: Slide-out cart with promo engine and multi-step checkout.

## Technology Stack

- **Framework**: Angular 19 (Standalone Components, Signals, Router, SCSS)
- **Animation**: GSAP 3, GSAP ScrollTrigger, Lenis Smooth Scroll
- **Styles**: Custom Luxury Cyber SCSS Design System

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm start
```
